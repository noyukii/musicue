Windows may flag this download as unsafe

MusiCue is not code-signed yet. Microsoft Defender’s machine-learning heuristic flags unsigned programs that few people have downloaded so far, so it may block MusiCue.exe or quarantine it as a trojan. This is a false positive.

On VirusTotal, 1 of 70 engines flags the v0.1.1 build — Defender’s own classifier. Every other engine reports it clean. Each release is built in the open from source by GitHub Actions, so you can check the binary yourself: SHA-256 d3f3795eef5e7cf36f638eb00aa8eaac6b13526fef5edd2e602a94577cbf8534

If it was already quarantined, open Windows Security → Virus & threat protection → Protection history, find the MusiCue entry and choose Restore. If SmartScreen blocks it instead, choose More info → Run anyway.
