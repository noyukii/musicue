    macOS may say MusiCue is damaged

    MusiCue is not notarized with Apple yet. Gatekeeper treats unsigned apps downloaded from the internet as damaged and refuses to open them.

    After unzipping, run the included If macOS says MusiCue is damaged, open this.command (right-click → Open if macOS blocks the helper too), or clear the quarantine in Terminal:

    xattr -cr /Applications/MusiCue.app

    Then open MusiCue normally. You can also allow it under System Settings → Privacy & Security.

    Windows may flag this download as unsafe

    MusiCue is not code-signed yet. Microsoft Defender may block MusiCue.exe or quarantine it as a trojan. This is a false positive.

    Each release is built in the open from source by GitHub Actions.

    If it was already quarantined, open Windows Security → Virus & threat protection → Protection history, find the MusiCue entry and choose Restore. If SmartScreen blocks it instead, choose More info → Run anyway.
