Start a workspace

MusiCue opens on a launcher. Start a new workspace or reopen a recent .musicue file. Audio files live inside that workspace, so you can copy the file to another machine without hunting for originals.

Add sound from the + menu, or drag WAV, AIFF, MP3, FLAC, or OGG files onto the cue list. Save with ⌘S / Ctrl+S. Save As writes a new .musicue file. Older .cue files are not opened.

If macOS refuses to open the app, or Windows flags the download, see the notes on the download page.

The booth

A workspace is one cue list plus a GO button. Top to bottom:

  • GO fires the standby cue and moves standby down the list.
  • Standby bar shows the next cue. Reset sends standby back to the top.
  • Notes is a free text strip saved with the workspace.
  • Toolbar adds cues, previews, stops, pauses, panics, and sets master level. The speaker button mutes the master without changing the fader.
  • Cue list is the show: number, name, target, pre-wait, duration, post-wait.
  • Inspector edits the selected cue. Hide it with ⌘I / Ctrl+I.

Edit vs Show: the mode button in the corner. Show hides the inspector and locks list edits so a stray click in the booth does not rewrite the plot. Playback still works.

GO, pause, panic

Standby is the cue that will fire next. By default, selecting a row also moves standby there. Turn that off in Settings if you want to inspect cues without changing the show position.

Press GO (Space). The standby cue starts, standby advances, and anything already playing keeps going. Overlap is the point: beds, stings, and walk-in can sit on top of each other.

  • Preview plays the selected cue without moving standby.
  • Stop stops the selected cue and anything nested under it.
  • Pause pauses or resumes everything currently playing.
  • Panic (Escape) stops all audio immediately. Escape still works while you are typing in a field.

A disarmed cue does not start. GO still advances past it. Assign a hotkey on the Triggers tab to fire that cue without touching standby — useful for bumpers and emergency stings.

Continue

Each cue has a continue mode on the Basics tab. New cues inherit the default from Settings.

  • Do not continue — wait for the next GO.
  • Auto-continue — when this cue finishes, wait for post-wait, then start the next sibling.
  • Auto-follow — one GO starts this cue and immediately fires the following auto-follow cues as well.

Audio, group, fade

The + menu adds an audio cue, a group, or a fade. Fade Selected… applies the same fade setup to one cue or every selected audio cue.

Indent and outdent nest cues under a group. Drag rows to reorder. Copy, paste, and duplicate work on the selected cues and their children. Undo reverses the last list edit.

Audio

One file, one row. Pre-wait delays the start. Fade in / fade out are baked into that cue. Trim sets in and out points on the waveform. Loop repeats the trimmed region until you stop it. Gain and pan apply immediately to running playback of that cue.

Groups

A group’s Mode tab decides what GO does to its children:

  • Timeline — start every child at once. Child pre-waits count from the group start. Standby jumps past the group.
  • Playlist — start the first child, then play the rest in order as each one finishes. Standby jumps past the group.
  • Start first and enter — start the first child and park standby on the next child, so later GOs walk through the group.
  • Start first — start only the first child, then leave the group. Child sequences can keep going on their own.
  • Start random — start one armed, idle child, cycling through them, then leave the group.

Fades

A fade cue rides level (and optionally pan) on other audio cues. Typical show use: fade the current song out and stop it, and fade the next one in from silence, starting it if it is not already playing.

  • Main track is the outgoing cue. Other track is the incoming cue, or nothing, or the next audio cue in the list.
  • Delay and Duration set when the move starts and how long it lasts.
  • Curve shapes the move: linear, ease in/out, S-curve, inverse S-curve, exponential, logarithmic, equal power.
  • Stop at end stops the outgoing cue when the fade finishes.
  • Stop fade: Hold targets leaves playing cues at their faded level if you stop the fade cue. Stop targets stops those cues instead.

Inspector

Tabs change with the selected cue.

  • Basics — number, name, notes, pre/post wait, continue, armed. Audio cues also get fade in and fade out.
  • Triggers — assign or clear a hotkey. The hotkey fires that cue without moving standby.
  • I/O — current output device. Per-cue routing is not available yet; audio goes to the main output.
  • Time & Loops — loop until stopped, file duration, playing duration after trim.
  • Levels — gain (−60 to +6 dB) and pan (−1 left to +1 right).
  • Trim — waveform with start and end points. Empty end means play to the file end.
  • Mode — group playback mode.
  • Fade — fade targets, curve, and stop behaviour.

Times accept seconds (3.5) or mm:ss.sss.

Settings

Open Settings with ⌘, / Ctrl+,.

  • Audio — output device, sample rate, buffer size.
  • Playback — whether standby follows selection, default continue mode for new cues, and a default master gain.
  • Shortcuts — click a binding, press a key, or clear it. Assigning a key already in use moves that key to the new action.

Master gain is also on the toolbar. Changing it in Settings updates the fader. The current fader value is saved in the workspace.
